### 동작 방식

**예측 모델** (`mijang/model.py`, GitHub Actions가 매일 한국시간 07:30에 다시 학습)

1. 지난 10년 동안 매월 말, 종목마다 **지표 31개**를 계산합니다.
   - 10대 수익률 지표: 누적수익률, CAGR, 변동성, 샤프, 소르티노, MDD, 칼마, 베타, 알파, 승률
   - 기술지표: 모멘텀(1·3·6개월, 12-1개월), 52주 고점/저점 대비, 50·200일 이동평균 괴리, RSI(14), MACD, 볼린저 %B, 1개월 변동성, 거래량 추세
   - **재무지표** (`mijang/fundamentals.py`, SEC EDGAR 공시): PER, PBR, PSR, ROE, 영업이익률, 매출 성장률, EPS 성장률, 부채비율
     - **그 날짜까지 공시된 숫자만** 씁니다(공시일 기준). 나중에 정정된 숫자가 아니라 처음 공시된 숫자를 씁니다.
     - 주식 분할은 공시 원본 단계에서 맞춥니다. 예: 애플 2019-06 PER 16.7, 엔비디아 2024-09 PER 57로 실제와 일치합니다.
     - 달러로 보고하지 않는 해외 기업(ASML 등), 적자 기업의 PER처럼 계산할 수 없는 값은 비워 두고, 모델에서는 "보통"으로 처리합니다.
2. 정답은 **그 뒤 3개월 동안 SPY(S&P 500)보다 더 올랐는지**입니다.
3. **예측 방법 20가지 + 이들을 섞은 혼합 4가지**를 과거 데이터로 겨룹니다. 항상 과거로만 학습하고 다음 해를 예측하는 워크포워드 방식입니다.
   - 팩터 규칙 12개: 모멘텀, 샤프 우수, 저변동성, 단기 반전, 추세 추종, 신고가 근접, 멀티팩터, **가치(저PER·PBR·PSR), 퀄리티(ROE·이익률·저부채), 성장(매출·EPS 성장), 가치+모멘텀, 성장+가치(GARP)**
   - 머신러닝 7개: 로지스틱 회귀, 릿지 순위회귀, 유사사례(k-NN), 그래디언트 부스팅, 랜덤 포레스트, 엑스트라 트리, 신경망
   - 앙상블 1개
4. 2020~2024년("선정 기간")에 **추천 적중률**(추천 20종목 중 SPY를 이긴 비율)이 가장 높은 방법을 고릅니다.
   최근 2년("검증 기간")은 방법을 고를 때 쓰지 않고, 고른 방법이 새 기간에도 통하는지 확인하는 데만 씁니다.
5. 고른 방법으로 후보 전체에 점수를 매겨 매수추천 20개를 뽑고, 종목마다 **근거**를 남깁니다.
   - **지표 31개 표**: 값, 오늘 후보 중 순위, 영향(그 지표를 '보통'으로 바꾸면 순위가 몇 %p 바뀌는지)
   - **이유 문장**: 영향이 큰 지표 3개. 예: `젠센 알파 +59.2% (상위 5%) → 점수 올림 +54%p`
   - **비슷한 과거 사례**: 과거에 지표 조합이 가장 비슷했던 50건이 3개월 뒤 실제로 어땠는지

**방법별 성적** (2026-09-25 학습 기준, 추천 20종목, 3개월 보유, 아무거나 고르면 적중률 47.6%, 검증기간만 보면 43.6%)

섞을 방법도 선정 기간 성적으로만 고르기 때문에 검증 기간은 끝까지 쓰지 않습니다.
섞어도 적중률은 단일 방법과 ±2~3%p 차이로 뚜렷하게 좋아지지 않았습니다. 다만 모델 하나에 기대지 않아 더 안정적입니다.
(스태킹과 규칙+ML 조합도 시험했지만, 선정기간과 검증기간 성적이 크게 엇갈려 뺐습니다.)

**솔직한 해석**
- 재무지표를 넣자 **단순한 "성장" 규칙**(매출·EPS 성장률 높은 순)이 선정기간 52.9%, **검증기간 54.7%**로
  두 기간 모두 버틴 첫 방법이 됐고, 자동으로 선택됐습니다. 다만 선정기간은 상위5 혼합과 동률이라 간발의 차입니다.
- 반대로 **머신러닝 모델은 재무지표를 넣자 오히려 나빠졌습니다**(가격 지표만 쓸 때 선정기간 약 55% → 51% 안팎).
  빈칸이 있는 입력 8개가 늘면서 신호보다 잡음이 더 커진 것으로 보입니다.
- **저PER·저PBR(가치)**은 이 기간 미국 대형주에서 통하지 않았습니다(선정기간 46.8%).
- 어떤 방법도 적중률이 55%를 크게 넘지 못합니다. 방법을 많이 비교할수록 1위가 운일 가능성도 커집니다.
- 후보가 **지금** S&P 100/나스닥 100에 있는 회사들이라(생존 편향) 실제 성과는 이보다 낮을 가능성이 큽니다.
- **참고용이며 수익을 보장하지 않습니다.**

## 수익률 10대 지표 (Python)

Yahoo Finance 데이터(`yfinance`)로 미국 주식의 수익률·위험을 10가지 지표로 계산합니다.

## 10가지 지표

| # | 지표 | 의미 | 해석 |
|---|------|------|------|
| 1 | 누적 수익률 (Total Return) | 기간 전체 가격 변화 `마지막가/첫가 - 1` | 배당 재투자 반영(수정주가) |
| 2 | CAGR | 연평균 복리 수익률 | 기간이 다른 종목끼리 비교할 때 |
| 3 | 연환산 변동성 | 일간 수익률 표준편차 × √252 | 높을수록 가격 출렁임이 큼 |
| 4 | 샤프 지수 | (수익률 − 무위험수익률) / 변동성 | 1 이상 양호, 2 이상 우수 |
| 5 | 소르티노 지수 | 샤프와 같지만 **하락** 변동성만 위험으로 봄 | 상승 변동성은 벌점 없음 |
| 6 | MDD (최대 낙폭) | 고점 대비 최대 하락률 | 최악의 경우 얼마나 물렸나 |
| 7 | 칼마 지수 | CAGR / \|MDD\| | 낙폭 대비 수익 효율 |
| 8 | 베타 | 벤치마크(기본 SPY) 대비 민감도 | 1보다 크면 시장보다 크게 움직임 |
| 9 | 젠센 알파 | 베타로 설명되지 않는 연 초과수익 | 양수면 시장 대비 초과 성과 |
| 10 | 일간 승률 | 상승 마감한 거래일 비율 | 50% 이상이면 오른 날이 더 많음 |

## 설치 & 실행

```bash
pip install -r requirements.txt

python -m mijang AAPL MSFT NVDA                 # 기본: 최근 1년, SPY 기준, 무위험 4%
python -m mijang TSLA QQQ --period 5y           # 기간: 6mo, 1y, 3y, 5y, 10y, max
python -m mijang AAPL --benchmark QQQ --rf 0.045
```

코드에서 직접 사용:

```python
from mijang import compute_indicators
result = compute_indicators(prices, benchmark=spy_prices, risk_free=0.04)
```
